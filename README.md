# CLonUI

Desktop UI toolkit / product for **CLon** (Solid Solutions / Fresh People ecosystem).

## Status

- CI: build, release, and Homebrew cask *verification* workflows live under `.github/workflows/`.
- The scheduled **Verify Homebrew Cask** job soft-skips until the first GitHub Release exists, then compares the latest release tag to the Homebrew cask version.
